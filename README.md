Clinical Pathway Process Mining Project

📌 Project Overview

The Clinical Pathway Process Mining Project analyzes healthcare processes using process mining techniques to understand patient journeys, discover workflow patterns, and identify bottlenecks in clinical pathways.

🎯 Objectives

- Analyze patient treatment pathways.
- Discover the actual flow of clinical processes.
- Identify bottlenecks and unnecessary delays.
- Compare actual workflows with expected clinical pathways.
- Improve healthcare process efficiency using data analytics.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Process Mining
- PM4Py
- Jupyter Notebook
